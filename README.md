# 瘟疫 · 传播模拟 Plague Simulator

一个基于个体的六城邦 SEIRD 传播沙盘。它不是预测工具，而是用来观察“病原体参数、环境与公共卫生干预如何共同改变一场瘟疫”的可交互模型。

**直接打开：** [`../瘟疫模拟器.html`](../瘟疫模拟器.html)（单文件，无外部依赖，无需联网或服务器）

![预览](preview.png)

## 玩法

- **空格** 暂停 / 继续；**R** 重置；右上角切换 1×–8× 速度。
- **点击地图上的城市**，向该城投放 8 例潜伏期感染者，制造新的火种。
- 悬停城市查看当地气温、现存病例、累计感染、死亡与床位占用；悬停曲线查看任意一天的数据。
- 左上角三个标签页分别调节 **病原体 / 环境 / 干预**。
- “干预”页可导出逐日数据 CSV。

## 模型

- 六座虚构城市、最多 8,000 名个体；每个人会移动、跨城旅行、接触、感染、康复或死亡。
- 疾病状态：易感 S → 潜伏 E → 感染 I → 康复 R / 死亡 D。
- 单次接触的传播概率近似为：

  `q = R₀ / (基础接触数 × 传染期) × 温度修正 × 个体状态修正`
- **温度**：每座城市的气温 = 基础气温 + 纬度偏移 + 季节波动。病原体有最适温度与温度敏感度；严寒会让人群转入室内（接触增加），极端高温/低温也会抬高病死率。
- **医疗容量**：重症患者占用床位，一旦超载，得不到救治的重症病死率显著上升。
- **年龄结构**：不同疾病有不同年龄风险曲线（如 1918 流感对青壮年尤其致命）。
- **干预**：口罩、病例隔离、旅行限制、社交距离、疫苗接种、医疗扩容；另有病毒变异开关。
- **免疫**：可设为终身免疫，也可设置持续天数；免疫消退后康复者重新变为易感者。

### 预设

| 场景       | R₀  | 潜伏期   | 名义病死率 | 特点             |
| -------- | --- | ----- | ----- | -------------- |
| 天花       | 5.0 | 12 天  | 25%   | 高传染、高致死、终身免疫   |
| 黑死病      | 2.2 | 4 天   | 45%   | 极高致死、近距离接触     |
| 1918 大流感 | 2.4 | 2.5 天 | 2.5%  | 低温放大传播、青壮年高危   |
| 麻疹       | 15  | 11 天  | 0.2%  | 传播力极强，需极高免疫率   |
| 埃博拉      | 1.8 | 8 天   | 50%   | 接触频率低、致死率高     |
| 新冠原始株    | 2.8 | 5 天   | 0.8%  | 无症状多、老年高危、免疫衰减 |
| 自定义      | —   | —     | —     | 自由调节所有参数       |

历史数值取自 WHO / CDC 与流行病学文献的常见区间，并做了教学化取整；城市、人口与接触网络均为虚构。

## 开发

```bash
# 重新打包（在 plague-sim 目录）
node tools/build.js

# 运行引擎回归测试
node tools/sim-test.js
```

## 边界

模型采用均匀混合 + 城市聚集的简化假设，没有真实的家庭/年龄接触矩阵、超级传播事件网络、疫苗分配策略与行为反馈。数值只用于理解机制，不能用于任何真实疫情的预测或决策。
